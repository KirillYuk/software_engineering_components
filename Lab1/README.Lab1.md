# Lab 1 `Домен і модель даних (ER)`

## Система онлайн-бронвання квитків на концерти та кінопокази

### Опис
Система створена для онлайн бронювання квиткі на концерти та кінопокази. Користувачі можуть переглядати доступні події, обирати місця, бронювати та оплачувати квитки. Заходи проводяться у визначених місцях із прономерованими місцями. Кожен захід може належати до одного або кількох жанрів.

Основні данні системи:
- користувачі
- місця проведення
- місця у місцях проведення
- події
- жанри
- бронювання
- квитки
- платежі
